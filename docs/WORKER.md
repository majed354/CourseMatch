# عامل CourseMatch على macOS

العامل يسحب المهام من API منصة CourseMatch. في البنية المحلية تحفظ خدمة الماك المهام في SQLite والملفات في مخزن خاص، وتصل واجهة Netlify الثابتة إلى الخدمة عبر وكيل cloudflared. يتصل العامل مباشرة بالخدمة على `http://127.0.0.1:8800` عند ضبط الوجهة المحلية، ويبقى عنوان المنصة العام HTTPS. العامل نفسه لا يفتح منفذًا. تُجرى قراءة PDF والبحث والتدقيق بالنماذج المحلية الموجودة في Ollama؛ لا يُنزّل نموذجًا ولا يرسل النص إلى نموذج سحابي.

## الإعداد الخاص

جهّز بيئة المشروع `.venv` ومتطلبات Python وTesseract العربية وOllama. يحتاج التدقيق النموذج المحلي `qwen3.8:27b-q8_0`، والبحث `qwen3-embedding:0.6b`، واسترداد الجداول المصورة `gemma4:e4b`.

أنشئ `.env.worker` داخل جذر المشروع بصلاحية `0600`، مملوكًا للمستخدم الذي يشغّل العامل. لا تحفظه في Git، ولا تضع قيمه في متغيرات LaunchAgent أو سطر الأوامر. يحتوي على:

```dotenv
COURSEMATCH_CLOUD_URL=https://YOUR-SITE.netlify.app
COURSEMATCH_LOCAL_URL=http://127.0.0.1:8800
COURSEMATCH_WORKER_TOKEN=REPLACE_WITH_THE_PRIVATE_WORKER_TOKEN
COURSEMATCH_WORKER_ID=mac-primary
```

`COURSEMATCH_CLOUD_URL` مطلوب ويجب أن يكون أصل HTTPS دون مسار أو بيانات دخول. طابقه مع أصل المنصة العام المضبوط للخدمة المحلية. `COURSEMATCH_LOCAL_URL` اختياري؛ قيمته الوحيدة المقبولة هي `http://127.0.0.1:8800` حرفيًا، دون شرطة مائلة أخيرة أو مسار أو query أو fragment أو بيانات دخول. لا يقبل `localhost` أو عنوانًا أو منفذًا آخر. عند حذف المتغير أو تركه فارغًا يستخدم العامل عنوان HTTPS العام؛ في البنية المحلية تحجب الخدمة طلبات العامل عبر المضيف العام، لذا يجب ضبط الوجهة المحلية. فشل الاتصال المحلي لا يبدّل الوجهة تلقائيًا إلى العنوان العام.

يمكن إضافة `COURSEMATCH_MODEL` لاختيار نموذج تدقيق محلي مثبت. تتقدم قيم البيئة المعروفة على قيم الملف. يقرأ الملف `key=value` حرفيًا، دون shell أو `eval` أو توسعة متغيرات. ترفض القراءة الملفات ذات صلاحيات المجموعة/الآخرين والروابط الرمزية. لا يطبع العامل السر أو محتوى المهمة أو بيانات المستفيد في سجلات التشغيل.

```bash
chmod 600 .env.worker
.venv/bin/python scripts/cloud_worker.py --once
```

الخيار `--once` يجرب الاسترداد/استلام مهمة واحدة. للتشغيل المستمر:

```bash
.venv/bin/python scripts/cloud_worker.py
```

يمنع قفل `flock` تشغيل عاملين في مجلد العمل نفسه. الانتظار الخامل الافتراضي 4 ثوان، ويرتفع تدريجيًا عند تعطل الاتصال حتى 60 ثانية. نبضة صحة العامل كل 30 ثانية، ونبضة حجز المهمة كل 20 ثانية؛ يُجدّد الخادم الحجز لمدة 15 دقيقة.

## LaunchAgent خاص بالمستخدم

عاين ملف الخدمة أولًا؛ هذا الأمر لا يكتب ملف خدمة ولا يشغّل العامل:

```bash
.venv/bin/python scripts/install-worker-macos.py --dry-run
```

بعد مراجعة الإعداد الخاص والتأكد من جاهزية الموقع، يُركّب صراحةً:

```bash
.venv/bin/python scripts/install-worker-macos.py --install
```

الخدمة `org.coursematch.worker` تستخدم `RunAtLoad` و`KeepAlive`، والمسارات المطلقة محفوظة كعناصر منفصلة حتى مع العربية والمسافات. تُشغّل Python بواسطة `/usr/bin/caffeinate -i` لمنع نوم الجهاز بسبب الخمول أثناء التشغيل. لا يغيّر المثبّت إعدادات النوم العامة ولا يستخدم `sudo`. يجب أن تكون جلسة المستخدم مسجلة الدخول وأن تظل Ollama متاحة. يحميه قفل العامل إن شُغّل يدويًا والخدمة تعمل بالفعل.

تحقق من الحالة دون عرض الأسرار:

```bash
launchctl print gui/$(id -u)/org.coursematch.worker
```

سجلات التشغيل داخل `runtime/cloud-worker/logs/` الخاص بالمستخدم. المثبّت يكتب plist بصلاحية `0600` ويضع مسار ملف السر فقط؛ لا ينسخ السر إلى plist.

## العقد مع المنصة

كل الطلبات تحمل `Authorization: Bearer <worker token>` وتستخدم بروتوكول الحجز نفسه في الوجهتين. العنوان العام يظل أصل HTTPS واحدًا؛ الاستثناء المحلي محصور بالعنوان المذكور أعلاه. التحويلات مرفوضة في الوجهتين، بما فيها التحويل من المحلي إلى HTTPS العام. لا يرسل العامل ترويسة `Origin`؛ تقبل الخدمة المحلية مسارات `/api/worker/` فقط مع `Host: 127.0.0.1:8800`، وتمنعها عند وصولها عبر المضيف العام أو مع `Origin` حتى لو صح السر. يلزم تشغيل الخدمة المحلية قبل العامل.

- `POST /api/worker/heartbeat` مع `worker_id`: صحة العامل الخامل.
- `POST /api/worker/claim` مع `worker_id`: يعيد `{task:null}` أو مهمة تحوي `id` بطول 32 خانة hex، و`session_id` بطول 64، و`lease_token` بطول 48.
- `POST /api/worker/tasks/:id/heartbeat` مع `lease_token`: تجديد حجز المهمة.
- `GET /api/worker/tasks/:id/input-pdf` مع `X-Lease-Token`: جلب PDF المصدر المربوط بالمهمة والجلسة. يستخدم أيضًا عند فقد النسخة المحلية لمصدر سبق رفعه.
- `POST /api/worker/tasks/:id/complete` مع `lease_token,result,error?`: حفظ النتيجة أو رسالة عربية آمنة مختصرة. تكرار الإكمال مع الحجز نفسه آمن؛ الحجز القديم يعيد `409`، والمهمة المنتهية `404/410`.

يحمل `payload.catalog_version` بصمة إصدار المكتبة الذي اختاره خادم المنصة، ويقارن العامل قيمته بالمكتبة المحلية. يبقى `catalog_id` في مهمة المصدر معرّف المقرر، و`target_id` هوية الهدف الفعلية المحددة في مكتبة الطائف. لا يقبل العامل مسار PDF من المستفيد.

## العزل والاسترداد

كل ملفات المصدر واستخراجه وذاكرة مقارنته داخل:

```text
runtime/cloud-worker/sessions/<session-id>/
  sources/<source-id>.pdf
  extraction/
  comparisons/
```

يعاد جلب المصدر من مخزن API عبر المهمة المحمية إن فقد من مجلد العامل، وتُطابق بصمته قبل الاستعمال. في البنية المحلية يبقى هذا المخزن الخاص على الماك. ملفات التوصيفات المستوردة تقرأ من `assets/` فقط بعد التحقق من بصمتها؛ لا تقبل مسارات مطلقة حتى إن وردت في مكتبة غير صحيحة. يعاد التحقق من المكتبة والمصادر بعد المقارنة أيضًا. `reviewed:true` مطلوب قبل التدقيق، وتظل سياسة 80/80/60 والحكم من البيانات غير المكتملة كما هما.

قبل إرسال النتيجة، يكتب العامل checkpoint ذريًا بصلاحية `0600` داخل `runtime/cloud-worker/checkpoints/`. يحتوي النتيجة وسياق المهمة وبصمة مدخلاتها والحجز الحالي؛ يعيد الإكمال بعد انقطاع الاتصال دون إعادة الاستدلال. عند إعادة حجز المهمة، يعاد استعمال الحساب نفسه فقط إذا تطابقت هوية المهمة والجلسة والمدخلات وإصدار المكتبة، وتستخدم قيمة الحجز الجديدة. يعاد التحقق من المصادر قبل إعادة الإقرار. لا تُرفع هذه الملفات أو الملفات الشخصية إلى Git أو النشر.

تضبط API مدة حفظ المهام والملفات والجلسات في مخزن الخدمة. ينظف العامل مرة كل ساعة checkpoints ومجلدات الجلسات المحلية التي لم تتغير منذ 24 ساعة؛ لا يمس المجلدات غير التابعة له أو الروابط الرمزية أو الملفات الحديثة. لا تحذف مجلد runtime يدويًا أثناء مهمة نشطة. لا تحتوي سجلات التشغيل payload أو الأسماء أو أرقام المستفيدين، لكن ملفات الجلسات/checkpoints نفسها بيانات خاصة.

## الاختبارات

```bash
.venv/bin/python -m unittest tests.test_cloud_worker -v
```

تغطي الاختبارات HTTPS وحصر الوجهة المحلية ومنع التحويلات، والسر الخاص دون تنفيذ shell، وملكية الجلسة والمسارات، وعزل مستفيدين، واستعادة PDF والتحقق من بصمته، وتحقق المكتبة قبل/بعد التدقيق، والمراجعة المطلوبة، ونبض الحجز وفقده، واستعادة النتيجة بعد ضياع الإقرار، والحجز الجديد، والتراجع التدريجي عند تعطل الشبكة، ومنع العامل المكرر، وplist عربي دون أسرار أو أوامر shell. تختبر رحلتان بروتوكول Python مع API الحقيقية في Node باستخدام مخزن ذاكرة: مباشرة، وعبر خادم HTTP المحلي الفعلي على منفذ عابر مع إبقاء Host المعتمد `127.0.0.1:8800`. تتحقق الرحلة المحلية أيضًا من حجب المضيف العام و`Origin` وغياب السر. تبقى النماذج ممثلة بـmocks؛ لا تشغّل هذه الاختبارات عاملًا دائمًا ولا تستخدم نماذج Ollama أو تشغل المنفذ 8800.
