# واجهة ومحرك CourseMatch

دليل المشروع المستقل وتشغيله واختباراته في [README.md](../README.md).
اسم المجلد داخلي موروث من مرحلة التجربة؛ المنتج الحالي هو منصة المعادلات CourseMatch.
لا يحتاج التشغيل إلى مستودع الخطط والتوصيفات أو ملفات خارجه.

التقرير الموجه للمستفيد يعرض الحكم والمقررين ونسب التغطية والأسباب الأكاديمية وختم التقرير.
الأصل المستخرج والقراءات المستكملة وبصمات المصادر والمحرك محفوظة في JSON وسجلات التدقيق.
